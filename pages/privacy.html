Privacy

This is a static website. There are no accounts, no forms, and no cookies set by this site. A few third-party services are involved, though, and this page lists them all.

Analytics¶

Page views are counted with GoatCounter, an open-source, privacy-friendly analytics service. It does not use cookies, does not track you across sites, and does not collect personal data. All it records is aggregate information such as the page visited, the referrer, the browser and screen size, and the country (derived from the IP address, which is not stored). See the GoatCounter privacy policy for the details.

If you block it, nothing on this site will break.

Comments¶

Comments on articles are powered by giscus, which stores them as GitHub Discussions. The comment widget is loaded from giscus.app and GitHub, and posting a comment requires signing in with a GitHub account. When you do, the GitHub privacy statement applies.
